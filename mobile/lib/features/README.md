# Mobile Features

[SafeStep Mobile overview](../../README.md)

Each folder below owns one user-facing capability. Shared networking, device services, and design foundations live in [core/](<../core/README.md>); app startup and route registration live in [app/](<../app/README.md>).

- [admin/](<admin/README.md>): administrator home.
- [alerts/](<alerts/README.md>): alert list and alert details.
- [auth/](<auth/README.md>): registration, login, and session state.
- [fall/](<fall/README.md>): fall checks and fall-event handling.
- [home/](<home/README.md>): role-specific home screens.
- [onboarding/](<onboarding/README.md>): initial role selection.
- [pairing/](<pairing/README.md>): guardian invitations and pairing.
- [realtime/](<realtime/README.md>): app-wide live connection state.
- [settings/](<settings/README.md>): preferences and accessibility controls.
- [sos/](<sos/README.md>): emergency request flow.
- [splash/](<splash/README.md>): startup and initial navigation.
- [tracking/](<tracking/README.md>): location capture, queueing, and map.
- [watching/](<watching/README.md>): guardian live view and route history.
