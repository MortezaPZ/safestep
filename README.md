# هم‌قدم — SafeStep

**سامانه‌ی هوشمند پایش ایمن و حفظ استقلال افراد دارای نیاز مراقبتی ویژه**

مبتنی بر گوشی هوشمند، بدون هیچ سخت‌افزار اضافه.

</div>

---

<div align="right">

کاربر نهایی می‌خواهد **مستقل** بیرون برود. خانواده‌اش می‌خواهند **نگران نباشند**.
این دو خواسته با هم در تنش‌اند، و کل طراحی این سامانه حول همین تنش شکل گرفته است:
کاربر همیشه می‌بیند چه کسی او را می‌بیند و با یک لمس می‌تواند قطعش کند — و در همان
حال، خانواده در لحظات بحرانی فوراً مطلع می‌شود.

## اجزای سامانه

| بخش | فناوری | وضعیت |
|---|---|---|
| بک‌اند | Node.js ۲۰+ · Express · PostgreSQL / PGlite | اجراشده و تست‌شده |
| اپ موبایل | Flutter / Dart | کامپایل‌شده، بیلد دیباگ اندروید |
| داشبورد وب | ES Modules خالص + Leaflet | اجراشده |
| پنل مدیریت | همان داشبورد، پشت گاردِ نقش | اجراشده |

هر سه کلاینت روی **یک قرارداد API** کار می‌کنند. هیچ endpoint اختصاصیِ یک کلاینت
وجود ندارد.

## اجرا

### روش ۱ — بدون هیچ پیش‌نیازی

</div>

```bash
cd backend
npm install
npm run seed
npm start
```

<div align="right">

سپس **http://localhost:4000** را باز کنید.

در این حالت دیتابیس روی درایور **PGlite** بالا می‌آید: همان PostgreSQL که به
WebAssembly کامپایل شده و درون همان پردازه‌ی Node اجرا می‌شود. نه Docker لازم
است، نه نصب PostgreSQL — و دقیقاً همان SQL و همان مهاجرت‌ها اجرا می‌شوند.

### روش ۲ — با Docker (مسیر رسمی استقرار)

</div>

```bash
docker compose up
```

<div align="right">

PostgreSQL واقعی بالا می‌آید و مهاجرت‌ها و داده‌ی نمونه خودکار اجرا می‌شوند.

### ساخت حساب مدیر

هیچ مسیر APIای برای ساخت ادمین وجود ندارد — کسی نمی‌تواند خودش را مدیر کند.
اولین ادمین فقط از خط فرمان ساخته می‌شود:

</div>

```bash
cd backend
npm run create:admin -- --phone 09121234567 --name "مدیر سامانه"
```

<div align="right">

رمز تصادفی یک بار روی ترمینال چاپ می‌شود. برای رمز دلخواه `--password` را اضافه کنید.

### اپ Flutter

</div>

```bash
cd mobile
flutter create --platforms=android,ios --org ir.safestep --project-name safestep .
flutter pub get
flutter run
```

<div align="right">

پوشه‌های `android/` و `ios/` عمداً در مخزن نیستند؛ محتوایشان به نسخه‌ی Gradle و
Xcode هر ماشین وابسته است. `flutter create` روی پوشه‌ی موجود، `lib/` و
`pubspec.yaml` را بازنویسی **نمی‌کند**.

پیش از اولین اجرا، مجوزها و کلید نقشه را طبق
[`mobile/PLATFORM_SETUP.md`](mobile/PLATFORM_SETUP.md) تنظیم کنید.

</div>

## قابلیت‌ها

### کاربر اصلی (فرد تحت پایش)

- ثبت‌نام و ورود با شماره موبایل
- **دعوت از مراقب با کد شش‌رقمی یا QR** — پیش از ساختن کد، خودش انتخاب می‌کند
  مراقب چه چیزی ببیند
- **ارسال موقعیت واقعی** با سرویس Foreground؛ در قطعی اینترنت در صف محلی
  می‌ماند و پس از وصل شدن دسته‌ای ارسال می‌شود
- **دکمه‌ی اضطراری** با نگه‌داشتن — حتی وقتی اشتراک‌گذاری موقعیت خاموش است
- کلید قطع فوری اشتراک‌گذاری، همیشه در دسترس
- تنظیمات دسترس‌پذیری: بزرگ‌نمایی متن تا دو برابر، کنتراست بالا، بازخورد لمسی

### مراقب

- اتصال با کد دعوت (ورودی متنی یا اسکن QR)
- **نقشه‌ی زنده‌ی Google Maps** با دایره‌ی دقت و نشانگر آنلاین بودن
- **تاریخچه‌ی مسیر** با انتخابگر روز، مسیر گرادیانی و خلاصه‌ی مسافت
- فهرست هشدارها با فیلتر نخوانده و «رسیدگی شد»
- دریافت زنده‌ی هشدار SOS با لرزش و اعلام صوتی

### مدیر سامانه

- مدیریت کاربران: جست‌وجو، تعلیق، فعال‌سازی، تغییر نقش، حذف نرم
- مدیریت دستگاه‌ها و ابطالشان
- مشاهده‌ی لاگ درخواست‌ها و لاگ حسابرسی
- **جدول ارزیابی**: دقت موقعیت‌یابی و تأخیر سیستم با میانگین و صدک‌های ۵۰/۹۵/۹۹

> ادمین به موقعیت یا تاریخچه‌ی **هیچ کاربری** دسترسی ندارد. اختیارش مدیریت
> سامانه است، نه نظارت بر افراد. یک تست اختصاصی این را قفل کرده است.

### موتور

- **Geofence با هیسترزیس**: باند مرده‌ی ۲۵ متری + debounce + دوره‌ی خاموشی
- تشخیص توقف طولانی با پنجره‌ی متحرک
- تشخیص قطع GPS و هشدار باتری کم
- WebSocket با اتاق به‌ازای هر کاربر
- آداپتور نوتیفیکیشن **FCM HTTP v1** با صف `notification_outbox` (بدون حساب سرویس روی مسیر محلی می‌ماند)
- محدوده‌ی دایره و چندضلعی، زمان‌بندی، هشدار ماندگاری، پینگ تطبیقی
- تشخیص سقوط SVM+KNN (آموزش پیش‌فرض مصنوعی)
- OTP پیامک با درایور `console` / کاوه‌نگار / قاصدک
- زبان: فارسی کامل؛ انگلیسی جزئی (تنظیمات وب، ناوبری، ورود/ثبت‌نام/خانه/هشدارهای موبایل)

## امنیت

| تصمیم | چرا |
|---|---|
| توکن access پانزده‌دقیقه‌ای + refresh چرخشی | سرقت توکن حداکثر یک چرخه دوام می‌آورد |
| توکن‌ها در Keychain/Keystore گوشی | SharedPreferences روی گوشی روت‌شده خواندنی است |
| نقش و وضعیت از دیتابیس، نه از توکن | تعلیق حساب باید فوری اثر کند، نه بعد از ۱۵ دقیقه |
| کد دعوت با HMAC-SHA256 هش می‌شود | نشتِ دیتابیس، اجازه‌ی حمله‌ی آفلاین نمی‌دهد |
| کنترل دسترسی در لایه‌ی SQL | امکان فراموش شدنش در لایه‌های بالاتر وجود ندارد |
| هیچ مختصاتی در لاگ نمی‌نشیند | لاگ عمر طولانی دارد؛ نشت تاریخچه‌ی حرکتی، همان تهدیدی است که محصول باید از آن محافظت کند |
| IP فقط به‌صورت HMAC | شمارش ممکن، بازیابی ناممکن |
| مسیر در لاگ به‌صورت الگو | `/alerts/:id` نه `/alerts/9f3c…` |

### تنش استقلال و ایمنی — در کد

وقتی کاربر اصلی اشتراک موقعیت را قطع می‌کند:

| رفتار | نتیجه |
|---|---|
| ثبت پینگ در دیتابیس | ✅ ادامه دارد — تاریخچه‌ی خودِ کاربر، مال خودِ اوست |
| پخش موقعیت به مراقبان | ❌ کاملاً متوقف |
| هشدار خروج از محدوده | ❌ متوقف — چون خودِ این هشدار هم یک نشت موقعیت است |
| دکمه‌ی اضطراری (SOS) | ✅ **همچنان کار می‌کند** — کاربر خودش آن را آغاز کرده |
