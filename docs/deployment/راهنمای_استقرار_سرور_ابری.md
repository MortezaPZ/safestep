# راهنمای گام‌به‌گام استقرار سرور ابری هم‌قدم (SafeStep Cloud Deployment)

این راهنما، نحوه استقرار سرور لینوکسی ابری با پایگاه داده PostgreSQL، گواهی امنیتی HTTPS و سرویس پیام‌رسان FCM را بر اساس الزامات پروژه شرح می‌دهد.

---

## ۱. پیش‌نیازهای ماشین میزبان (VPS)
- سیستم‌عامل پیشنهادی: **Ubuntu 22.04 LTS** یا **Ubuntu 24.04 LTS**
- مشخصات سخت‌افزاری: حداقل ۲ هسته CPU، ۴ گیگابایت RAM، ۴۰ گیگابایت SSD
- یک دامنه یا زیردامنه با رکورد `A` که به IP عمومی سرور اشاره می‌کند (مثال: `api.hamghadam.ir`)
- باز بودن پورت‌های ۸۰ (HTTP) و ۴۴۳ (HTTPS) در فایروال

---

## ۲. نصب ابزارهای مورد نیاز روی لینوکس
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git nginx certbot python3-certbot-nginx docker.io docker-compose

# فعال‌سازی و راه‌اندازی داکر
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

---

## ۳. انتقال کدها و راه‌اندازی سرویس
۱. کدها را به مسیر `/opt/safestep` منتقل کنید:
```bash
sudo mkdir -p /opt/safestep
sudo chown $USER:$USER /opt/safestep
cd /opt/safestep
```

۲. فایل متغیرهای محیطی را از روی قالب بسازید:
```bash
cp deployment/.env.production.example deployment/.env
```
رمزهای تصادفی امن تولید کنید و در فایل `deployment/.env` قرار دهید:
```bash
openssl rand -hex 32  # برای JWT_ACCESS_SECRET
openssl rand -hex 32  # برای JWT_REFRESH_SECRET
openssl rand -hex 32  # برای INVITE_CODE_PEPPER
openssl rand -hex 32  # برای IDENTITY_DATA_ENCRYPTION_KEY
```

۳. فایل کلید اختصاصی فایربیس (`safestep-fcm-service-account.json`) را در مسیر `deployment/secrets/` قرار دهید:
```bash
mkdir -p deployment/secrets
# قرار دادن فایل کلید فایربیس در این پوشه
chmod 600 deployment/secrets/safestep-fcm-service-account.json
```

۴. اجرای سرویس‌ها با داکر:
```bash
cd deployment
docker-compose -f docker-compose.prod.yml up -d --build
```

---

## ۴. اجرای مایگریشن‌ها و ساخت حساب مدیر سامانه
> **مهم:** دستور `npm run seed` را به هیچ وجه اجرا نکنید. فقط دستورات زیر مجاز هستند:

```bash
# ۱. اجرای ساخت و به‌روزرسانی جداول پایگاه داده
docker exec -it safestep-backend npm run migrate

# ۲. ایجاد حساب ادمین اصلی با رمز عبور قوی
docker exec -it safestep-backend npm run create:admin -- --phone 09120000000 --fullName "مدیر سیستم" --password "YourStrongPassword2026!"
```

---

## ۵. تنظیم وب‌سرور Nginx و گواهی SSL (HTTPS)
۱. تنظیم فایل کانفیگ Nginx:
```bash
sudo cp deployment/nginx.conf /etc/nginx/sites-available/safestep
# جایگزینی YOUR_DOMAIN.ir با دامنه واقعی در فایل
sudo sed -i 's/YOUR_DOMAIN.ir/api.hamghadam.ir/g' /etc/nginx/sites-available/safestep
sudo ln -s /etc/nginx/sites-available/safestep /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl restart nginx
```

۲. دریافت خودکار گواهی رایگان SSL (Let's Encrypt):
```bash
sudo certbot --nginx -d api.hamghadam.ir
```

---

## ۶. بررسی سلامت سرویس (Health Check)
پس از انجام مراحل فوق، مسیرهای زیر در مرورگر یا با دستور `curl` بررسی شوند:
```bash
curl -I https://api.hamghadam.ir/health
# باید پاسخ HTTP/2 200 با وضعیت سلامت بازگرداند
```
سپس پنل وب در آدرس `https://api.hamghadam.ir` با حساب مدیر قابل دسترس است.
