# گزارش نهایی فازهای دو و سه — هم‌قدم

**تاریخ:** ۱۵ شهریور ۱۴۰۵
**وضعیت:** تحویل‌شده با محدودیت‌های صادقانه

## ۱. خلاصه‌ی یک‌بندی

FCM نسخه‌ی HTTP v1 با صف ارسال، محدوده‌های چندضلعی و زمان‌بندی، تشخیص سقوط با SVM و KNN، تأیید شماره با درایور پیامک قابل تعویض، تست بار، و پوشش جزئی زبان انگلیسی روی سامانه‌ی فاز اول سوار شد. دادهٔ آموزش سقوط پیش‌فرض مصنوعی است؛ iOS روی ویندوز بیلد نشده است.

## ۲. قبل و بعد

| | پیش | پس |
|---|---|---|
| نوتیفیکیشن | ساختار | FCM v1 + outbox |
| Geofence | دایره | چندضلعی، زمان‌بندی، ماندگاری، پینگ تطبیقی |
| سقوط | فقط طرح جدول | مدل + API + شمارش معکوس + ماتریس درهم‌ریختگی |
| OTP | نبود | console / کاوه‌نگار / قاصدک |
| تست بار | نبود | autocannon + گزارش ارزیابی |

## ۳. چه چیزی تحویل شده

مهاجرت‌های `003` تا `005`، آموزش `npm run train:fall`، اسکریپت `npm run loadtest`، پنل ادمین با ماتریس سقوط، اپ Flutter با صفحهٔ بررسی سقوط.

پوشش انگلیسی جزئی است: وب (انتخاب زبان در تنظیمات + برچسب ناوبری)، موبایل (`login`، `register`، `roleSelect`، `home`، `alerts`). بقیهٔ رشته‌ها فارسی می‌مانند و در `en` نباید کلید خام دیده شود.

## ۴. چطور آزموده می‌شود

چک‌لیست پذیرش (۱۵ شهریور ۱۴۰۵):

```

npm run train:fall                         # knn F1=1.000 svm F1=0.980 (synthetic)

flutter build apk --debug                  # app-debug.apk
npx @redocly/cli lint openapi.yaml         # valid، ۱۱۰ warning
thesis-guide.pdf                           # ۳۶۰ KB
```

`GET /health` → ۲۰۰، درایور `pglite`، نوتیفیکیشن `local`، پیامک `console`. `GET /api/docs` باید ۲۰۰ باشد.
