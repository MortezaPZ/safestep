# گزارش بازتولید آموزش مدل سقوط SisFall

این گزارش با اجرای `npm run train:fall:sisfall` تولید شده است.

## منشأ داده و بازتولید

دادهٔ خام در مخزن نگهداری نمی‌شود. منبع قابل‌بازتولید، mirror مجموعه در [Hugging Face](https://huggingface.co/datasets/Trupal7/Sisfall_Dataset/tree/f8a95e5c953169985dc9641e1a5772e6b7b47a83) و آرشیو [SisFall_dataset.zip](https://huggingface.co/datasets/Trupal7/Sisfall_Dataset/resolve/f8a95e5c953169985dc9641e1a5772e6b7b47a83/SisFall_dataset.zip) در commit ثابت `f8a95e5c953169985dc9641e1a5772e6b7b47a83` است. کارت این mirror مجوز CC BY 4.0 را اعلام می‌کند؛ مقالهٔ اصلی SisFall را [Sucerquia و همکاران، ۲۰۱۷](https://doi.org/10.3390/s17010198) ارجاع دهید. ورودی از پوشهٔ ضبط خام محلی خوانده می‌شود. انتظار می‌رود داده از آرشیو mirror زیر تهیه شود؛ hash آرشیو ZIP برابر 7f0dd1583e39fee0f402a6855976eb12517f7eaecdacce871d5b3421793ad665 است. خود اسکریپت آرشیو را دانلود یا hash آن را کنترل نمی‌کند؛ اجراکننده باید منشأ و hash را جداگانه کنترل کند.

README داخل آرشیو ۴٬۵۱۰ فایل را اعلام می‌کند، اما در همین revision تعداد فایل‌های ضبط با نام‌گذاری داده ۴٬۵۰۵ است: ۱٬۷۹۸ سقوط شبیه‌سازی‌شده و ۲٬۷۰۷ فعالیت روزمره. README منبع می‌گوید شرکت‌کنندگان سالمند فقط فعالیت روزمره را اجرا کردند، به‌جز SE06 که متخصص جودو بود و سقوط‌ها را هم شبیه‌سازی کرد؛ بنابراین این اعتبارسنجی، عملکرد سقوط در سالمندان ناتوان را ثابت نمی‌کند. پنج فایل `D17_SE15_R01..R05.txt` در پوشهٔ `SA15` قرار دارند؛ تبدیل‌گر شناسهٔ پوشه را بر شناسهٔ داخل نام فایل مقدم می‌گیرد. این اختلاف و قاعده در راهنمای داده ثبت شده‌اند.

## آموزش و اعتبارسنجی

- ردیف‌های ویژگی: 4505
- برچسب داده: `sisfall-public-simulated-falls`
- KNN (k=9): دقت 98.16%، precision 97.82%، recall 97.55%، F1 97.69%
- Linear SVM: دقت 97.00%، precision 96.63%، recall 95.83%، F1 96.23%
- قاعدهٔ ترکیبی: دقت 97.98%، precision 98.08%، recall 96.83%، F1 97.45%
- زمان آموزش: 2026-11-13T09:18:15.430Z

اعتبارسنجی subject-grouped nested cross-validation است؛ مقیاس‌بندی درون هر fold برازش می‌شود و تنظیم ابرپارامتر در foldهای داخلی انجام می‌شود. جاروب ۴۸ ترکیب threshold از امتیازهای out-of-fold در `docs/evaluation/fall-rule-threshold-sweep.csv` نوشته شده است. این نتایج جای ارزیابی روی افراد/پیاده‌روی مستقل و دادهٔ واقعی محصول را نمی‌گیرند. سقوط‌های SisFall در آزمایش شبیه‌سازی شده‌اند و سقوط ناخواسته در محیط واقعی نیستند.
