# یادداشت تحویل

محتویات هر بسته باید پیش از ارسال با فایل‌های واقعی آن تطبیق داده شوند. آرشیو قدیمی `SafeStep-client-delivery-2026-11-01.zip` از نسخهٔ فعلی مخزن حذف شده تا داخل بستهٔ تازه قرار نگیرد. ZIP به‌روزشده از snapshot نسخهٔ ثبت‌شدهٔ مخزن ساخته می‌شود؛ وجود سورس به‌تنهایی به معنی APK امضاشده یا سرویس Firebase پیکربندی‌شده نیست.

برای آزمایش میدانی به سرور عمومی با HTTPS، حساب‌های ایجادشده برای همان آزمایش، پیکربندی Firebase و نسخهٔ release امضاشده نیاز است. دستورهای سرور و راهنمای کلید در `docs/deployment/mobile-release-and-container.md`، مراحل کلاینت در `docs/mobile-client.md` و فایل‌های لازم Firebase در `docs/firebase-setup-for-client.md` آمده‌اند. نشانی HTTP محلی برای نسخهٔ release مناسب نیست. از حساب‌های دمو و seed در پایگاه واقعی استفاده نکنید.

نمونه‌های GPS و پاسخ‌های SUS باید از پیاده‌روی و شرکت‌کنندگان واقعی به دست آیند. نتایج آزمایش دستگاه، دریافت FCM، امضای APK و استقرار HTTPS فقط پس از انجام و ثبت شاهد واقعی قابل تأیید هستند.
