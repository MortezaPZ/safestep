## محدودیت‌هایی که به داده یا دسترسی بیرونی نیاز دارند

- نمونه‌های خطای GPS باید در پیاده‌روی واقعی کنار نقطهٔ مرجع نقشه‌برداری‌شده جمع شوند؛ SUS باید از شرکت‌کنندگان مستقل گرفته شود.
- آرشیو خام SisFall در بسته نیست، اما mirror عمومی pin‌شده و hash آن در `backend/data/falls/README.md` آمده و بازآموزی از همان نسخه اجرا شده است. دریافت دوباره به اینترنت نیاز دارد؛ یک CSV گروه‌بندی‌شدهٔ دلخواه با `SISFALL_FEATURE_CSV` نیز از نظر منبع/مجوز توسط اسکریپت تأیید نمی‌شود.
- برای زمان نمایش هشدار روی گوشی به حساب سرویس FCM، گوشی ثبت‌شده و ثبت رسید واقعی نیاز است. `alert_deliveries` فعلی زمان پذیرش/پاسخ کانال سرور را می‌سنجد، نه زمان نمایش روی گوشی.
- آزمون ۱۰ دقیقه‌ای پس‌زمینه به گوشی واقعی نیاز دارد. APK امضاشده نیز به کلید انتشار متعلق به صاحب برنامه نیاز دارد.
- Pub.dev مستقیم در این محیط HTTP 403 می‌دهد؛ `flutter pub get` با `PUB_HOSTED_URL=https://pub.flutter-io.cn` موفق شد و lockfile به URL canonical `https://pub.dev` برگشت داده شد. سه تست Flutter پاس شدند. analyzer با `--no-fatal-infos --no-fatal-warnings` بدون خطای کد exit 0 داد، ولی ۵ warning و ۲۶ info دارد و اجرای پیش‌فرض به‌علت همین diagnostics exit 1 می‌دهد. debug APK با گواهی Debug تأیید شد و release APK با mirror artifactهای Flutter ساخته شد، اما unsigned است. برای امضای انتشار به کلید مالک برنامه نیاز است. |
- lockfile فعلی با Flutter 3.47.2 حل شده و حداقل SDK ثبت‌شده در آن Flutter 3.47 است؛ `mobile/pubspec.yaml` هنوز Flutter >=3.22 و Dart >=3.4 اعلام می‌کند. build و آزمون‌ها فقط روی Flutter 3.47.2 انجام شده‌اند؛ سازگاری lockfile با نسخه‌های قدیمی‌تر بررسی نشده است.
- مهاجرت قدیمی ۰۱۱ ردیف‌های تکراری را بدون آرشیو حذف می‌کرد. نسخهٔ فعلی پیش از حذف آرشیو می‌کند و مهاجرت ۰۱۳ جدول آرشیو را در پایگاه‌های موجود ایجاد می‌کند؛ اگر حذف قدیمی قبلاً روی پایگاه واقعی اجرا شده، ردیف‌های پاک‌شده فقط از backup قابل بازیابی‌اند و باید وضعیت/backup آن پایگاه پیش از انتشار بررسی شود.
- قرارداد Kavenegar کلید را در مسیر URL می‌گذارد؛ برای هدرمحور بودن باید provider دیگری مثل قاصدک انتخاب شود یا لاگ مسیر در پراکسی پاک‌سازی شود.
- Dockerfile اصلاح شده ولی Docker CLI در محیط موجود نیست؛ ساخت image اجرا نشده است.
