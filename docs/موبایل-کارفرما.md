# اپ موبایل هم‌قدم برای کارفرما

این فایل برای نصب و تست روی گوشی اندروید است. سورس را لازم نیست اجرا کنید اگر فایل `APK` را دارید.

## ۱. نصب اپ

فایل `hamghadam.apk` کنار پروژه یا داخل `safestep/docs/` است (حدود ۱۸۰ مگ، نسخه‌ی دیباگ).

1. فایل را به گوشی بفرستید.
2. روی فایل بزنید و نصب کنید. اگر گوشی هشدار «منبع ناشناس» داد، اجازهٔ نصب از همان برنامه (فایل یا واتساپ) را بدهید.

## ۲. سرور روی رایانه

روی همان رایانه‌ای که بسته را باز کرده‌اید:

```bash
cd backend
npm install
npm run seed
npm start
```

در مرورگر رایانه باید باز شود: `http://localhost:4000`

گوشی و رایانه باید به **یک وای‌فای** وصل باشند.

آی‌پی رایانه را پیدا کنید:

- ویندوز: `cmd` بعد `ipconfig` — مقدار `IPv4`
- نمونه: `192.168.1.25`

در اپ، فیلد «آدرس سرور» را این‌طور بگذارید:

```text
http://192.168.1.25:4000
```

عدد را با آی‌پی خودتان عوض کنید. `localhost` روی گوشی کار نمی‌کند.

## ۴. اگر از Android Studio می‌سازید

پوشهٔ `mobile` را باز کنید. یک‌بار:

```bash
cd mobile
flutter pub get
flutter create . --platforms=android
flutter run
```

برای گوشی واقعی همان آدرس سرور را در صفحهٔ ورود بگذارید.

روی ویندوز فایل `IPA` آیفون ساخته نمی‌شود.
